# Fotografie — John-Luke Finance Outsourcing

Plaats foto's in deze map met **exact** de bestandsnaam hieronder (extensie `.jpg`, `.jpeg`,
`.png` of `.webp`). Ze verschijnen automatisch op de website en worden bij de build
geoptimaliseerd (AVIF/WebP, meerdere formaten). Lever liggende foto's aan van minimaal
1600 px breed.

**Richtlijnen:** echte, natuurlijke zakelijke fotografie. **Geen mensen of menselijke figuren**,
geen cartoons, robots, 3D-renders of drukke technologiebeelden. Gebruik per plek een andere foto.
Gebruik alleen foto's waarvoor u een licentie heeft (eigen foto's, of bijv. Unsplash/Pexels).
